♟ Live-тренер

устанавливается на ваш компьютер ← на главную

Что это

Панель на chess.com, которая после каждого хода показывает вердикт: лучший ход, неточность, зевок, жертва. Движок Stockfish работает на вашем компьютере, в вашем браузере. Позиции никуда не отправляются, у автора сайта нет ни сервера, ни доступа к вашим партиям. Эта панель — отдельная программа, а не часть сайта.

⚠️ Fair play. Правила Chess.com запрещают использовать движок в партиях против людей — и в рейтинговых, и в нерейтинговых. Панель годится только для игры против компьютера, тренировки и разбора уже сыгранных партий.

Установка

  1. Скачайте проект. На странице репозитория нажмите Code → Download ZIP и распакуйте, либо выполните git clone <адрес репозитория>.
  2. Поставьте Stockfish. 
    sudo apt install stockfish
    На Windows и macOS скачайте сборку с stockfishchess.org и запомните путь к исполняемому файлу.
  3. Поставьте менеджер userscript. Tampermonkey или Violentmonkey.
  4. Запустите локальный сервер в папке проекта: 
    ./start.sh
    На Windows: python server.py. Если Stockfish лежит не в PATH: 
    python3 server.py --engine /путь/к/stockfish
    Окно терминала должно оставаться открытым, остановка — Ctrl+C.
  5. Откройте http://127.0.0.1:8765/ и нажмите «Установить userscript». Tampermonkey покажет окно установки. Можно установить и с этой страницы: Установить userscript
    Сервер должен быть запущен: userscript обращается только к 127.0.0.1:8765 на вашем компьютере.
  6. Откройте chess.com и начните партию. Панель появится справа снизу; её можно перетащить за заголовок, двойной клик возвращает в угол.

Приватность

Локальный сервер слушает только 127.0.0.1 — то есть доступен исключительно с вашего компьютера. Userscript отправляет позиции только на этот адрес. Никакой аналитики, аккаунтов и внешних запросов, кроме загрузки страницы chess.com, нет. Логи разобранных партий сохраняются в папку games/ на вашем диске.

Live-тренер не входит в публичный сайт: он ничего не знает об авторе и не связан с его компьютером. Каждый пользователь запускает свою копию. Лицензии: Stockfish (GPLv3), chess.js (MIT).
